# 参数指南

[English](SETTINGS.md) | [简体中文](SETTINGS.zh-CN.md)

按 **F10**，修改数值后点击**保存并生效**。参数立即应用，并保存到 `config/autofish-recovery.properties`。**恢复默认数值**只填入默认值，点击保存后生效，并保留当前钓鱼开关。**返回**或 **Esc** 关闭界面，**Tab** 在输入框之间切换。

## 时序参数

| 参数 | 默认值 | 范围 | 到期时的操作 |
|---|---:|---:|---|
| 重抛等待 | 500 ms | 100–10000 ms | 收竿后允许再次抛竿，同时等待旧鱼钩消失。 |
| 抛竿失败重试 | 5000 ms | 2000–60000 ms | 仍然没有鱼钩时重试抛竿，不会延迟已有鱼钩的咬钩处理。 |
| 启用/重连等待 | 5000 ms | 1000–60000 ms | 开启钓鱼或恢复有效玩家、世界与鱼竿后，允许首次抛竿。 |
| 无咬钩超时 | 10000 ms | 6000–600000 ms | 在水中的鱼钩存续时间达到上限、仍未检测到咬钩时收竿。 |
| 非水区域超时 | 20000 ms | 10000–60000 ms | 未入水的鱼钩存续时间达到独立上限时收竿。 |
| 旧鱼钩清理等待 | 3000 ms | 1000–10000 ms | 已收竿的鱼钩未正常消失时，清理残留的客户端引用。 |

识别到咬钩后，在下一个客户端 tick 直接收竿；重抛和启动计时不会额外延迟这次收竿。收竿后会等待旧鱼钩消失再重抛，异常清理的超时与重抛等待分别计时。

请根据实际游玩的服务器调整。无咬钩超时太短会在鱼儿到来前提前收竿；重抛等待太短，在延迟较高或限制物品使用频率的服务器可能导致抛竿被忽略。

## 检测与保护

| 参数 | 默认值 | 范围或行为 |
|---|---:|---|
| 下沉检测阈值 | 0.05 | 0.01–1.0；用于判断咬钩时的鱼钩向下运动。 |
| 咬钩声音距离 | 1 方块 | 0.1–5 方块；接受自己鱼钩附近的咬钩声音。 |
| 声音检测 | 开启 | 在下沉检测之外，使用 `entity.bobber.splash` 声音事件。 |
| 耐久保护 | 开启 | 可损坏鱼竿仅剩 2 点或更少耐久时停止使用。 |
| 自动钓鱼 | 首次使用时关闭 | 开关会保存，重新启动客户端后继续使用。 |

下沉阈值太低可能把普通摆动当成咬钩；声音距离过大可能包含附近玩家的鱼钩。最近鱼钩检查会减少误判，鱼钩完全重叠时仍难以区分。

声音检测监听游戏事件，不采集麦克风或扬声器声音。通过操作系统静音不会影响该事件。游戏内音量为零时可能跳过部分声音处理；依赖声音检测时，请保持相关滑块高于零。未收到咬钩声音事件时，下沉检测仍然工作。

## 界面与后台

在仍然运行的多人世界中，聊天、背包、容器菜单和参数界面可以保持打开并继续钓鱼。模组不会激活 Minecraft 窗口或重新捕获鼠标。

后台使用时，请把 Minecraft 配置为失去焦点后继续运行。单人世界被暂停时不会继续出鱼。断线、死亡或旁观者模式会暂时阻止鱼竿使用；恢复有效玩家、世界并重新手持鱼竿后会恢复钓鱼。
